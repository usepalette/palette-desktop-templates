# Foundations — GTM

What this space **knows**: the reference material to load before working here, not the work itself. Stable, rarely changing, and the first thing to read before producing anything in this space.

## Files

| File | Read it when |
|---|---|
| [`gtm-strategy.md`](gtm-strategy.md) | You need the motion, the channels, the current phase or the bets: before planning a campaign, a launch or a piece of positioning work |
| [`sales-narrative.md`](sales-narrative.md) | You are telling the story: a sales call, a deck, a pitch, a landing page |

Copy [`_template.md`](_template.md) when a new reference is written, such as how the team prices or its plan for a channel, and list it here. Create a file when the content exists; don't create empty stubs.

## What belongs here

**Rule of thumb:** if it is stable and you would load it before starting a task, it belongs here. If it is a way of thinking, it is a [playbook](../playbooks/README.md); if it has steps, it is a [process](../processes/README.md); if it is something the team found out, it is [research](../research/README.md); if it is work with a start and an end, it is a [project](../../../projects/README.md).
