# New customer

Add a customer, a client or an account, whatever this company calls the people it serves.

Say "we just signed a new customer", or name the command.

1. You need the name. Everything else is written only as far as it was given.
2. Follow [`customers/README.md`](../../customers/README.md) → Add a customer. Check its "When to create a folder" first: not every lead needs one.
3. Say what you made, and what is still blank.

## It adapts

- **Use what you were given.** Anything the person wrote after the command, or earlier in the chat, counts. Ask only for what is still missing, in one round.
- **The steps live in one place.** Follow the page named above. If that page says something different from this one, the page wins.
- **If the page named above is missing, stop.** It was renamed or removed. Look in the map in the root `README.md` for where customers live now and use that. If there is no place for them, say so and ask whether to set one up. Never rebuild a missing folder or its mold from memory.
