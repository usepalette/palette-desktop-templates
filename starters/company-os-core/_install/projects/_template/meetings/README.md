# Meetings — [Project name]

One file per meeting, named `YYYY-MM-DD-topic.md`, copied from [`_template.md`](_template.md). A decision made in a meeting also gets a dated `Decision:` line in the project's [`README.md`](../README.md); a milestone that moved gets updated in the README's Milestones table.
