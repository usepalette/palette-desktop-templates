# Painpoints

Problems synthesised from one or more sources. They describe the pain, not the solution someone asked for.

## When a painpoint is made

Create or update a painpoint when:

- the same underlying problem shows up in at least two independent sources, or
- a structured interview shows a clearly blocking problem. If it is the only source, say so.

One casual complaint is never a recurring pattern.

## File shape

[`_template.md`](_template.md) is the shape of a painpoint, named `YYYY-MM-DD_company_topic.md`. Say "we keep hearing this" ([`../../processes/synthesise-feedback.md`](../../processes/synthesise-feedback.md)) rather than copying it by hand, so the sources, the scores and the company profiles stay in step. Never rebuild its fields from memory.
