# User interviews

Longer conversations with customers or users: discovery interviews, sessions with design partners, research calls and structured usability debriefs.

## File shape

[`_template.md`](_template.md) is the shape of an interview. Copy it here as `YYYY-MM-DD_company_person_topic.md`, or say "here are my notes from the interview" ([`../../processes/capture-feedback.md`](../../processes/capture-feedback.md)). Never rebuild its fields from memory.

After an interview that raised several problems or asks, synthesise it: [`../../processes/synthesise-feedback.md`](../../processes/synthesise-feedback.md).
