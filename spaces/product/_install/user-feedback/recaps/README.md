# Feedback recaps

Sourced summaries saved for sharing with a team, a customer or a stakeholder.

A recap is saved here only when someone asks to keep one made with [`../../processes/share-feedback.md`](../../processes/share-feedback.md). Name it `YYYY-MM-DD-<company-or-topic>.md`.

Every recap carries `source_files`, linking the exact feedback, interviews, requests and painpoints it sums up. A recap is a message about the evidence, not new evidence: never cite one as a source.
