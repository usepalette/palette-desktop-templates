# New project

Start a project: work with a beginning and an end.

Say "we're starting a new project", or name the command.

1. You need the name and one line on what it is for. Owner, dates and customer are written when they are known.
2. Follow [`projects/README.md`](../../projects/README.md) → Start a project.
3. Say what you made, and what is still blank.

## It adapts

- **Use what you were given.** Anything the person wrote after the command, or earlier in the chat, counts. Ask only for what is still missing, in one round.
- **The steps live in one place.** Follow the page named above. If that page says something different from this one, the page wins.
- **If the page named above is missing, stop.** It was renamed or removed. Look in the map in the root `README.md` for where projects live now and use that. If there is no place for them, say so and ask whether to set one up. Never rebuild a missing folder or its mold from memory.
