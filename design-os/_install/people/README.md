# People

One folder per designer: who they are, how to work with them, and their drafts. Agents read the person's `README.md` and `lessons.md` before every task, so the more a profile says, the better the work fits.

## Add a person

1. **Copy `_template/` whole** to `people/<first-name>/` in one go. Don't retype its files.
2. **In the copy, fill in the name, email and role** the person gave. Leave "How to work with me" for them, or for agents to propose over time. A working style is never invented.
3. **Add a row** to the table above.
4. **Ask them** to give their agent access to the repos and design files, following [`../repos.md`](../repos.md).

## What goes in a person's folder

- **`README.md`** — who they are and how to work with them.
- **`drafts/`** — one folder per thing they are exploring. See the `README.md` inside.
- **`lessons.md`** — what agents learned about working with them.
- **`log.md`** — what happened in their work.

Only the owner edits their own folder, or an agent acting for them. A person's folder is not private, and drafts are meant to be found by the rest of the team.
