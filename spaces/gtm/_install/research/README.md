## Add research

1. **Check it isn't here already.** Look in this folder, and in the market pages in [`company/market/`](../../../company/market/README.md), for the same question.
2. **Write one file,** `YYYY-MM-DD-<topic>.md`, named for the question it answers. It opens with full frontmatter: `type: research`, the owner, `status`, the date, the acting person and the edit policy. Say what was asked, what was found, and where each finding comes from, with a link and a date.
3. **Add its row** to the table above, newest on top, replacing the "None yet" row if it is the first.
4. **Write back what lasts.** A sourced fact about a competitor goes in that competitor's file in [`company/market/competitors/`](../../../company/market/competitors/README.md). A finding that changes who we sell to or how we position is proposed for [`company/market/ideal-customer.md`](../../../company/market/ideal-customer.md) or [`company/brand/messaging.md`](../../../company/brand/messaging.md), and written after a yes. A finding that changes the plan goes in [`foundations/gtm-strategy.md`](../foundations/gtm-strategy.md). The research file links to where each one went.

Research for one project lives in that project's folder in [`projects/`](../../../projects/README.md), not here.
