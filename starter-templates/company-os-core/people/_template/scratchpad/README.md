# Scratchpad — [Full Name]

The workbench: drafts, experiments and imports whose final home is not clear yet. Work can stay here for weeks, but everything here is a proposal. Nothing in this folder is a source of truth, and nothing here is "decided".

## Current work

_None yet._ One line per item while it lives here: a link to the file or folder, then what it is and what it is waiting for. The line is added in the session the item is made, and removed when the item is promoted or dropped.

## How to keep it usable

- **One working file per thing.** Improve it in place. No `-v2`, no `-final`, no copy per round.
- **A topic with more than one file gets its own folder,** with a `README.md` that says what it is, which file is the working one, and where it stands: proposed, promoted or dropped.
- **A loose file starts with its date:** `YYYY-MM-DD-slug.md`.
- **Promote when it becomes real:** when a page outside this folder links to it, or a second person relies on it, it moves to the folder it belongs to and the copy here goes.
- **Reworking something that is already live?** Draft the new version here and swap it in when it is approved.
- **No heavy files.** Images, video and exports stay in the tool or drive the company keeps them in.
- **Not a task list, and not private.** Tasks live in the task home named in `company/tools.md`, and the workspace's real permissions decide who can read this.
- **Old items get looked at.** A workspace check lists what nobody has touched for about a month: keep, promote or delete.
