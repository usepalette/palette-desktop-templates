# Create space

Make a new space under `spaces/`. A space is any area of work that needs its own rules and memory: a team's home, a discipline several people share, or a body of work. Name it the way the person names it.

Say "we need a space for product", or name the command.

1. You need what the space is for and who owns it. Check first that it deserves a space and not a page or a project: [`spaces/README.md`](../../spaces/README.md) → When something deserves a space.
2. Follow [`spaces/README.md`](../../spaces/README.md) → Add a space.
3. Say what you made, and which parts of it are still empty.

## It adapts

- **Use what you were given.** Anything the person wrote after the command, or earlier in the chat, counts. Ask only for what is still missing, in one round.
- **The steps live in one place.** Follow the page named above. If that page says something different from this one, the page wins.
- **If the page named above is missing, stop.** It was renamed or removed. Look in the map in the root `README.md` for where spaces live now and use that. If there is no place for them, say so and ask whether to set one up. Never rebuild a missing folder or its mold from memory.
