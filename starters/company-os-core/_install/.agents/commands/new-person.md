# New person

Add someone to the workspace: a colleague, or the person in the session.

Say "add a colleague", or name the command.

1. A colleague needs their full name and role; their email when it is known, never guessed. The person in the session is started from the email the host supplied.
2. Follow [`people/README.md`](../../people/README.md) → Add a person, or → Getting started here when it is the person in the session.
3. Say what you made, and what is still blank for them to fill in.

## It adapts

- **Use what you were given.** Anything the person wrote after the command, or earlier in the chat, counts. Ask only for what is still missing, in one round.
- **The steps live in one place.** Follow the page named above. If that page says something different from this one, the page wins.
- **If the page named above is missing, stop.** It was renamed or removed. Look in the map in the root `README.md` for where people live now and use that. If there is no place for them, say so and ask whether to set one up. Never rebuild a missing folder or its mold from memory.
