# Processes — GTM

**How things are done here**: step-by-step, specific, actionable. A process can stand alone or be referenced by a [playbook](../playbooks/README.md). The playbook says *why and how to think*; the process says *what to do, in which order*.

A process written this way can be handed to an agent as it stands: say the words in its row, or name the process, and the steps are followed in order. That is the progression: first a person reads it, then an agent runs it.
