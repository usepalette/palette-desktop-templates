# Add playbook

Write down how a piece of work is done, so the next person and the next agent do it the same way. It becomes a playbook (how to think about it), a process (steps in order), a template (a format to reuse) or a foundation (what is known), whichever fits.

Say "let me explain how we do this", or name the command.

1. Listen first: take what the person explains, in their words. Don't pad it into more than they said.
2. Find the space it belongs to in [`spaces/README.md`](../../spaces/README.md), and follow that space's own `README.md` → Capturing how the work is done.
3. If no space fits yet, say so: offer to make one, or keep the draft in the person's scratchpad until there is a home.

## It adapts

- **Use what you were given.** Anything the person wrote after the command, or earlier in the chat, counts. Ask only for what is still missing, in one round.
- **The steps live in one place.** Follow the page named above. If that page says something different from this one, the page wins.
- **If the page named above is missing, stop.** It was renamed or removed. Look in the map in the root `README.md` for where spaces and their playbooks live now and use that. If there is no place for them, say so and ask whether to set one up. Never rebuild a missing folder or its mold from memory.
