# Import

Bring existing material into the workspace: documents, a shared folder, a website, connected tools, or what another AI tool knows about the person's work.

Say "I want to bring in what I already have", or name the command.

1. If nothing was handed over yet, say which ways there are and take them one at a time.
2. Follow [`../import.md`](../import.md). It holds the request to give another AI tool, and the rule that matters most: show where each piece would go and wait for a yes before writing anything.
3. End with what was filed, what was held back and why.

## It adapts

- **Use what you were given.** Anything the person wrote after the command, or earlier in the chat, counts. Ask only for what is still missing, in one round.
- **The steps live in one place.** Follow the page named above. If that page says something different from this one, the page wins.
- **If the page named above is missing, stop.** Say that the import procedure is gone and ask how to go on. Never file material from memory of how it used to work.
