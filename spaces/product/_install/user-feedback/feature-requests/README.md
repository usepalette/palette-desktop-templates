# Feature requests

Explicit capabilities users asked for. A request is evidence, not a commitment on the roadmap.

## File shape

[`_template.md`](_template.md) is the shape of a request. Copy it here as `YYYY-MM-DD_company_topic.md`, or say "capture this feedback" ([`../../processes/capture-feedback.md`](../../processes/capture-feedback.md)). Never rebuild its fields from memory.

Before creating a request, search for the same underlying job. When it is a duplicate, add the new source to the existing request's `source_files` instead.
