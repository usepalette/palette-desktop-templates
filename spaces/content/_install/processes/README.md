# Processes — Content

**How things are done here**: step-by-step, specific, actionable. A process can stand alone or be referenced by a [playbook](../playbooks/README.md). The playbook says *why and how to think*; the process says *what to do, in which order*.

A process written this way can be handed to an agent as it stands: name the process, or say the words in the table, and the steps are followed in order. That is the progression: first a person reads it, then an agent runs it.

## Processes

A piece moves through them in this order, and each one also runs on its own when someone asks.

| Process | Run it when |
|---|---|
| [`start-a-piece.md`](start-a-piece.md) | Someone asks for a piece that goes out: "help me write a LinkedIn post about…", "draft this month's newsletter" |
| [`refine-a-piece.md`](refine-a-piece.md) | A draft needs tightening: "tighten this draft", "this is too long" |
| [`check-the-voice.md`](check-the-voice.md) | Someone asks "does this sound like us?", or a piece is about to go to review or out |
| [`plan-distribution.md`](plan-distribution.md) | Someone asks "where should this go?" or "what else can this become?", or a piece goes out without a plan |
| [`publish-a-piece.md`](publish-a-piece.md) | A piece went out: "we published this today", with the link |

Copy [`_template.md`](_template.md) to add one, and list it here. Change a process when the team works differently, and log the change in the space's [`log.md`](../log.md).
